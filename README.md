# Michelson Interferometer from Recycled Components

This repository contains the design files for the 3D-printed parts used in a low-cost Michelson interferometer built from recovered optical components, a laser pointer, and locally available mechanical materials.

The purpose of this repository is to document the design strategy and provide a starting point for reproducing or adapting the optomechanical components of the project.

## Contents

The repository includes:

- STL files for the 3D-printed optomechanical parts.
- FreeCAD source files, when available.
- A folder with photographs documenting parts of the construction and assembly process.

The photographs are included as supplementary documentation to help understand how the printed parts were used in the experimental setup.

## Design philosophy

The interferometer was built using optical components recovered mainly from discarded CD/DVD drives. Because these components are not standardized, their dimensions, mounting points, and optical alignment requirements may vary from one user to another.

For this reason, the project should not be treated as a fixed kit to be printed exactly as provided. Instead, the files should be understood as a reference design and a practical starting point. In many cases, it will be more convenient to adapt the parts to the optical and mechanical components available to each user.

The STL files are useful because they show the geometry, proportions, mounting logic, and mechanical arrangement used in the prototype. However, users are encouraged to modify the designs when necessary, especially if their recovered mirrors, beam splitter, lenses, laser pointer, screws, or base dimensions differ from those used in the original build.

Whenever possible, editing the source files in FreeCAD is recommended instead of modifying the STL files directly.

## Notes for users

Before printing the parts, users should check:

- the dimensions of their recovered optical components,
- the diameter and geometry of the laser pointer,
- the size and pitch of the screws available,
- the thickness and material of the base,
- the required optical height of the system,
- the alignment range needed for the mirrors and beam splitter.

The original design was developed for a specific set of recovered components. Therefore, small changes in component dimensions may require redesigning or scaling some supports.
